# 问答质量评测 v1

题集依据仓库 100 页 HES9570 手册，页码为 PDF 页序号。创建于本轮功能开发期间，覆盖参数、表格、条件、步骤、易混淆、多轮和资料不足；在首次运行后不得再称为未见盲测。未使用其结果修改检索算法。它与旧题集仍存在主题重叠，不等于完全独立的外部测试，正式上线前需另请业务人员补充真实问题并审核标准答案。

```bash
.venv/bin/python scripts/evaluate_quality.py --mode local
.venv/bin/python scripts/evaluate_quality.py --mode live --limit 5
.venv/bin/python scripts/verify_live.py
```

默认本地评测不调用供应商。live 模式明确使用当前已配置的 Embedding/回答服务，发送问题与检索片段，会产生费用；按顺序运行并限制样本数。verify_live 使用临时数据库、临时 PDF 和纯测试文本验证真实上传、向量索引、混合检索、流式生成与持久化，不修改用户知识库。

报告默认写入忽略的 output/quality/，包含输入题集 SHA256、文档 SHA256/索引版本、供应商模型名（不含密钥）、检索页码命中、证据字符串覆盖、降级、错误、耗时和生成结果。文档校验绑定仓库手册，避免其他文档的同页码被误计为命中。引用编号有效与证据字符串覆盖不代表答案正确。

模型回答的事实正确性、完整性、拒答是否合理由人工审核；报告中 human_review 为 pending。请填写事实正确、条件完整、无编造、引用支持四项，再统计答案正确率。不得用模型成功返回或引用编号有效替代正确率。
